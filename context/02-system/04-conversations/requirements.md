# 02-system/04-conversations — Conversations Requirements

Prefix: `TEAM.SYS.CONV`

The Conversations Package owns Channels, signed Markdown Messages, Channel participation and cryptographic policy, domain policy, local schemas and projections, offline behavior, and unread state. In Phase 4 every current Workspace Member participates in every Channel, so the Package has no separate Channel Membership records. It consumes Canonical Membership as an eligibility ceiling and SHALL NOT mutate it. Peer replication uses the generic `teamarness.synchronization.immutable-record-log` capability rather than a Conversations-specific Core Runtime branch. Phase 4 version 1 uses one content key with creator-only bootstrap and current-holder grants. Core retains raw-key custody and performs the generic protection and grant mechanics without exposing raw keys to the Package. Revocation gates direct future writes and synchronization but does not claim to erase retained historical key material. A synthetic `#general` Channel is permanent and cannot be hidden; other Channel hide is permanent with no restore path.
