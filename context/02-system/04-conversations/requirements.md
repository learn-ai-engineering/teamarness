# 02-system/04-conversations — Conversations Requirements

Prefix: `TEAM.SYS.CONV`

The Conversations Package owns Channels, signed Markdown Messages, Channel Membership, conversation keys, domain policy, local schemas and projections, offline behavior, and unread state. It consumes Canonical Membership as an eligibility ceiling and SHALL NOT mutate it. Peer replication uses the generic `teamarness.synchronization.immutable-record-log` capability rather than a Conversations-specific Core Runtime branch. Phase 4 version 1 uses one content key with creator-only bootstrap and current-holder grants; revocation gates future writes and synchronization but does not claim to erase retained historical key material. A synthetic `#general` Channel is permanent and cannot be hidden; other Channel hide is permanent with no restore path.
